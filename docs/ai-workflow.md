# AI 工作流

本项目使用 Codex 辅助拆解、实现、验证和修改代码，不使用真实 AI 服务加工素材。

1. 将需求拆为模板与素材、匿名身份、任务受理、后台三步执行、前端状态和容器交付，明确 Java / Next.js / MySQL 的职责。
2. 提供状态机、接口字段、数据结构和参考布局作为上下文；将“事务提交后分派”“查询只读”“失败中断”“任务按 ID 隔离”“旧响应不能覆盖新状态”列为约束。
3. 按模块生成和修改源码、SQL、Dockerfile、Compose 与测试，不整体复制已有业务项目。
4. 在容器中执行 lint、类型检查、前端 / Java 测试和构建，再用真实 MySQL 与文件卷运行接口验收；检查结果图片、阶段记录和个人隔离。
5. 根据编译和测试失败输出修正问题，再运行受影响检查。浏览器用于核对主要布局、上传、任务恢复、图片预览和小屏操作。

具体例子：恢复某条任务时，原实现只刷新历史第一页。增加组件测试后，修改为按 taskId 请求详情；查询失败保留旧快照，成功读到终态后停止轮询。再通过延迟 Promise 验证旧上传和旧用户响应不会污染当前数据。

其他修正包括：中文种子的 UTF-8 初始化、模拟参数类型检查、接口字段 camelCase、关闭演示模式时隐藏切换入口、按模板返回的类型 / 大小校验上传，以及取消和释放离开页面后的请求。验证结果按实际容器输出记录，远程 CI 未执行的部分保持标注。
